# OSK.Storage.Local
This project provides an implementation of the [Storage Abstractions](https://github.com/OpenSourceKingdom/OSK.Storage.Abstractions) for use with local devices.

## 📖 Documentation
For further information about the library, usage, etc., please visit the **[Docs Page](https://opensourcekingdom.github.io/OSK.Storage.Local/)** (or check the `/docs` folder).

# Contributions and Issues
Any and all contributions are appreciated! Please be sure to follow the branch naming convention OSK-{issue number}-{deliminated}-{branch}-{name} as current workflows rely on it for automatic issue closure. Please submit issues for discussion and tracking using the github issue tracker.
